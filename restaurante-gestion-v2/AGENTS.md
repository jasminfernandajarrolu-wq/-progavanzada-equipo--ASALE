# AGENTS.md

## Descripción
Sabores Bolivianos: sistema de gestión para un restaurante de comida típica boliviana.
Proyecto de Programación Avanzada. Solo frontend.

## Stack
- React + Vite
- CSS en src/index.css
- lucide-react (iconos)
- Datos en localStorage

## Estructura
- src/components/views/ (Header, LoginView, Modal, Navigation, Toast, DashboardView y demás vistas)
- src/data/ (authData.js, seedData.js)
- src/hooks/useRestaurantState.js (estado global)
- src/App.jsx, src/main.jsx
- src/index.css (estilos)

## Comandos
- npm install
- npm run dev

## Reglas
- La interfaz va en español.
- Leer docs/constitution.md y memory.md antes de empezar cualquier tarea.

## Límites
- No modificar src/hooks/useRestaurantState.js sin avisar.
- No agregar librerías sin preguntar.
- No subir claves reales: el repositorio es público.
- Preguntar antes de crear o borrar archivos.
