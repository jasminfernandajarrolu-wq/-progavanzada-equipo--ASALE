# SDD: /implementar

Comando para implementar incrementalmente el código en SDD.

## Instrucciones

Implementa solo la siguiente tarea pendiente (`- [ ]`) de `specs/<funcionalidad>/tasks.md`.

1. Realiza los cambios de código correspondientes a esa tarea exclusivamente.
2. Marca la tarea como hecha (`- [x]`) en `specs/<funcionalidad>/tasks.md`.
3. Actualiza `memory.md` con los avances o contexto relevante aprendido.
4. Indica detalladamente al usuario qué archivos cambiaste.
