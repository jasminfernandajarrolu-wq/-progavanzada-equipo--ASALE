# SDD: /clarificar

Comando para la fase de clarificación y control de calidad de la especificación en SDD.

## Instrucciones

Revisa `specs/<funcionalidad>/spec.md` como si fueras un analista de calidad.

1. Lista ambigüedades, contradicciones y requisitos que falten.
2. Corrige la spec (`specs/<funcionalidad>/spec.md`) con lo que encuentres.
3. Explica claramente al usuario qué cambios realizaste.
